# Smart Classroom Attendance System

A web-based project designed to explore QR-code-based
student attendance management and classroom noise monitoring.

## 🎯 Problem Statement

Manual attendance can be time-consuming and prone to errors.
Classroom noise can also affect the learning environment.

## 💡 Project Overview

This project combines a QR-code attendance workflow
with a classroom noise monitoring component.
